Note generali:
- Il progetto è una webapp React (Vite) con routing (`react-router-dom`) e mappa in doppia modalità: Google Maps “complessa” e MapLibre “semplice”.
- Stile con TailwindCSS, grafici con Recharts, icone Lucide e gestione stato utente via `UserContext`.
- La lingua UI e documentazione sono in italiano.
